# Published experiment evidence

This directory contains a compact export of the full run `cuda-222416`, started on October 24, 2026 (UTC). The smoke run is excluded. It contains 6 configurations × 3 workloads × 3 concurrency levels × 3 repetitions = 162 cells, with 128 measured requests per cell, 128 output tokens per request, and zero measured failures.

| File | Contents |
|---|---|
| `cells.csv` | Original full-run cell summaries, including per-run quantiles and wall durations |
| `requests.jsonl.gz` | All 20,736 measured requests, with cell identifiers, token counts, and HTTP event times; gzip-compressed JSON lines |
| `cache_counters.csv` | Selected original prefix-cache counters before/after each cell, including warmup traffic |
| `environment.json` | Recorded versions, hardware, tokenizer metadata, and server arguments (local executable path omitted) |
| `pip-freeze.txt` | Recorded installed package inventory; editable/local-file installation entries omitted |
| `SHA256SUMS.json` | SHA-256 integrity hashes for the five evidence files above |

The public export deliberately excludes prompt text, generated samples, error text, GPU UUIDs, local filesystem paths, and server logs. The full local experiment folders remain outside Git. This is sufficient to check the summary arithmetic and rebuild the figure; it is not a complete archive of prompts or server internals. Workload text is generated by `lab/workloads.py`.

Run from the repository root:

```bash
python scripts/validate_evidence.py
python scripts/research_figure.py
```

Request timestamps are seconds relative to each cell's start; cells have independent clocks. They represent client HTTP events, not exact per-token timestamps or GPU scheduler events. p50/p95/p99 in the CSV are per-cell quantiles using linear interpolation. The report and figure take medians of per-run summaries, with min–max ranges where shown. These ranges are not confidence intervals.

Cache counter names are preserved from Prometheus. The “before” snapshot occurs **before warmup**, so before/after differences include both warmup and measured traffic. They are not measured-only hit rates. GPU model was checked across all configuration/repetition telemetry files. The driver and memory capacity were recorded in the job's initial `nvidia-smi` output; the CUDA value is driver-reported, not a claim about the installed toolkit. The recorded tokenizer commit is null and the model revision was not pinned.

The package inventory documents the actual run environment; it includes packages beyond this project's needs and should not be treated as a minimal installation requirements file. Use `pyproject.toml` and `scripts/setup_cuda.sh` for installation.
